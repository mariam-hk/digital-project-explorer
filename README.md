# TechLocation AI — Digital Market Explorer (مستكشف السوق الرقمي)

منصة تفاعلية لاستكشاف السلوك الرقمي للمجتمع في المحافظات والمدن لمساعدة رواد الأعمال والمستثمرين في تحديد الموقع والنموذج الأمثل لمشاريعهم التكنولوجية، بالاستناد إلى بيانات وإحصائيات موثقة.

---

## 🌟 مميزات المنصة (Key Features)

1. **استكشاف محدد حسب الموضوع (Topic Exploration)**:
   - 📱 **الهواتف الذكية (Smartphones)**: معدلات انتشار الهواتف الذكية وتفضيل الموبايل.
   - 🌐 **الإنترنت (Internet)**: استخدام الإنترنت اليومي والشبكات المنزلية والخلوية.
   - 💻 **أجهزة الحاسوب (Computers)**: توفر بيئات العمل وأجهزة الكمبيوتر للمهام المعقدة.
   - 🎓 **المهارات الرقمية (Digital Skills)**: الكفاءة التقنية وحجم خريجي كليات التكنولوجيا والهندسة.
   - 🛒 **التسوق الإلكتروني (Online Shopping)**: سلوك الشراء عبر التطبيقات والمنصات.
   - 💳 **المدفوعات الرقمية (Digital Payments)**: استخدام المحافظ الإلكترونية والبطاقات المصرفية مقابل الكاش.

2. **ملف رقمي شامل لكل محافظة (Governorate Digital Profiles)**:
   - بغداد، أربيل، البصرة، السليمانية، النجف، نينوى (الموصل)، كربلاء، بابل، والمعدل المرجعي لعموم العراق.
   - بطاقات إحصائية تفاعلية مع شريط مقارنة تلقائي مع المعدل الوطني.

3. **تحليل الذكاء الاصطناعي المؤسس على الأرقام ("What does this mean?")**:
   - لا يخترع أرقاماً ولا يعطي ادعاءات عشوائية.
   - يلخص فرص السوق للمشاريع الناشئة (Commercial Opportunities).
   - يسلط الضوء على التحديات والمخاطر الميدانية (Risks & Bottlenecks).
   - يقترح أفضل النماذج التكنولوجية الملائمة للمحافظة المختارة (Best-fit Tech Models).

4. **مقارنة مباشرة بين مدينتين (Head-to-Head Comparison)**:
   - مقارنة تفاعلية لأي مدينتين (مثل بغداد مقابل أربيل) مع إظهار فوارق النسب بالأرقام والأشرطة المرئية.

5. **دعم كامل للغتين (Arabic & English)**:
   - واجهة سلسة تدعم العربية (RTL) والإنجليزية (LTR) بضغطة زر واحدة.

6. **الشفافية الكاملة وتتبع المصادر (Data Auditability)**:
   - علامة واضحة لبيانات العرض التجريبي (`Demo Data — Replace with verified dataset`).
   - جدول تفصيلي للمصادر وسنوات الجمع والتعاريف المنهجية لكل مؤشر.

## 🏗️ هيكلية المشروع (Project Architecture)

- `src/lib/types.ts`: تعريف عقود البيانات والمؤشرات.
- `src/lib/data/iraq-digital-data.ts`: البيانات المنظمة للمحافظات والمؤشرات الوطنية.
- `src/lib/ai/interpreter.ts`: محرك التفسير التحليلي الاستراتيجي.
- `src/components/`: المكونات التفاعلية (Header, TopicSelector, LocationSelector, MetricCard, AIInsightBox, CityComparisonModal, DataSourcesModal).
- `src/app/page.tsx`: صفحة التطبيق التفاعلية الرئيسية.
